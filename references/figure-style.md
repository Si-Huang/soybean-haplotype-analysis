# 固定绘图规范

默认中文报告、英文图文。优先使用 `scripts/style.py`：白底、DejaVu Sans、去上右边框，PDF 可嵌入 TrueType、SVG 保留文本，PNG 300 dpi。轴标题 14 pt、刻度 12 pt、图标题 16 pt、图例 12 pt；多位点／多类型时先扩大画布或分页，不优先缩小文字。

|含义|固定颜色|
|---|---|
|Wild / Soja|#3182A0|
|Landrace|#DEA126|
|Improved|#CC5656|
|A / C / G / T|#73A65B / #E3A06F / #7A9FC4 / #397CA0|
|缺失|浅灰，并在图注说明|
|R / ER / N / S 原始标签|#0072B2 / #2266AD / #888888 / #D95F02|

类别配色只是视觉约定，不自动定义抗性。H/P 编号按本次来源顺序稳定；同一次报告的同一编号保持颜色一致。跨基因 H1 不代表同一种生物学类型。类型超过 12 种应分页或使用标签补充，不能仅靠循环色辨认。

矩阵每格保留状态文字；启动子显示相对注释边界位置，CDS 显示基因组位置，蛋白显示 1-based 氨基酸位置。长 Indel 状态用源表链接及合理缩写，并在图注解释。存在数十个位点时助手拆页或面板，不输出拥挤长条图后直接交付。

两种频率图分开命名并写明分母及 N 的单位。没有观测的群体不画成有意义的零频率。表型图逐字段显示有效 n，条内数字是材料数，缺数据类型仅标 n=0。

MST 节点面积表示拷贝数，扇区表示群体；边数字是保留位点状态差异。用图例明确这些语义，不使用暗示祖先和选择方向的箭头。

交付前打开 PNG：检查文字清晰、无重叠裁切、图例不盖数据、两类百分比和源表相符、N/n 单位正确。与用户指定风格冲突时遵循用户当次要求。
