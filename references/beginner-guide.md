# 给第一次做单倍型分析的你

单倍型可以理解成“同一区域里一组共同出现的变异组合”。一个 SNP 是一个位置的差别，单倍型把多个位置合在一起看。同一密码子的多个 SNP 可能共同改变一个氨基酸，因此 TF 分支还会把完整组合翻译成蛋白类型。

## 从一句话开始

“这个基因是我的靶基因，帮我看启动子单倍型。”或者“这个基因是 TF，帮我看 CDS／蛋白单倍型”。再给基因编号；不知道版本时直接说不知道，助手先查。靶基因与 TF 身份可能重叠，按你想研究的调控环节选区域。

第一次先跑 README 的合成练习，确认能生成报告和图。再使用真实基因；不要用练习数据填补真实项目缺失。

## 先读哪几张图

1. **矩阵**：每行一种组合，先看主要类型在哪里不同。H1 只是编号，不等于最优型或祖先型。
2. **群体内频率**：野生、地方、改良群体分别有哪些类型，比例多少。
3. **类型内组成**：某一类型来自哪些群体。它与上一张图分母不同，答案也不同。
4. **网络**：当前保留位点定义的组合有多相似。靠得近和边短不能直接证明进化先后。
5. **蛋白图（TF）**：多个 CDS 类型是否编码同一种预测蛋白，哪些氨基酸位置不同。
6. **表型图（有记录才画）**：先读 n，再读比例。只有 1 个材料时的 100% 与 100 个材料时的 100% 证据强度不同。

## 三个常见误读

“H1 在改良群体多，所以它被人工选择。”——频率差异只是线索，还需采样、群体结构和选择分析证据。

“没有表型记录，所以这个类型不抗病。”——缺记录只代表不知道，不能补成零或感病。

“有非同义突变，所以功能一定改变。”——需结合结构域、表达、结合或遗传实验。预测蛋白不同只是候选机制。

## 交付时应看到什么

`report_zh.md` 讲清楚基因、版本、分析范围、完成模块和未完成原因。`figures/` 是 PDF/SVG/PNG 图；CSV 是图的源数据；`run_audit.json` 记录输入哈希和本次状态。原始数据库响应在输入目录 `raw/`。

遇到角色不明、编号映射失败、CDS 不匹配、表型冲突或服务故障时，让助手说明具体缺什么。合理的“这个模块暂时不能解释”比看似完整的假结果更有价值。
